# Preview of the project first Stage

首先得搞明白这个项目是干嘛的，第一阶段是搭建一个RAG**静态知识库**。

## RAG Tech

RAG将信息检索组件和文本生成模型组合到一起，RAG可以微调。其内部知识的修改方式非常高效，无需额外的背景知识。

RAG接收输入，并且检索出一组相关/支撑的文档，并且附上文档的来源。这些文档作为上下文，和输入的Prompt相组合，送给**文本生成器**得到最终的输出。

对于一个project，我们需要对其中的信息进行提问。但是我们不可能每次都从project中整理过去，所以需要把这堆信息给知识库。每次提问的时候，我们可以选择对应的知识库，然后其帮助我们携带**文本向量**去匹配知识，最后扔给AI大模型进行提问。

文本知识库的来源多种多样，不一定非得是文字。把数据get到之后，开始解析处理。然后将文件进行切割，存储到向量模型。经过**打标**（标记这是哪里来的，搞什么用的）之后，存储到向量库里面去。这也即是所谓的**文本向量化**。
