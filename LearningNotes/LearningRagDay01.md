## Learn Docker initially

之前也用过docker，但是仅仅是使用，并没有深入去理解其背后的底层原理。这个以后得好好学一下

Docker作为一个用于开发、发布和运行应用程序的开放平台，可以将应用程序和基础架构进行分离。

这边实际上有一个延伸的问题，也是我之前在面试中所遇到过的：**docker和虚拟机的差别在哪里？**

与虚拟机的安装使用相比，docker会将应用所需要的依赖、函数库、甚至是其他的软件应用都一起打包，最终形成一个**镜像**。这样的话，在应用程序运行的时候，就可以直接去调用本地的函数库，最终和Linux内核去进行通信。这个特点有点像 Java 里的虚拟机，也就是JVM。说到这边，突然发现我对于JVM也是学了个半吊子，今年上半年一定要好好补一下。
